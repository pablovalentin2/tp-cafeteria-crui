# API Cafetería CRUI

API REST para la administración de productos de la cafetería, desarrollada con Node.js y Express.

## Instalación de dependencias
Para instalar los módulos necesarios (Express), abrir la terminal en la carpeta del proyecto y ejecutar:
\`\`\`bash
npm install
\`\`\`

## Ejecución del servidor
Para iniciar el servidor, ejecutar el siguiente comando:
\`\`\`bash
node index.js
\`\`\`
El servidor comenzará a ejecutarse y estará escuchando peticiones en `http://localhost:3000`.
